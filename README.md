# mineral-zone

Arkana Duszy — statyczny projekt oraz wersja motywu WordPress.

## WordPress
Motyw znajduje się w katalogu `arkana-duszy-theme`. Skopiuj go do
`wp-content/themes/`, a następnie aktywuj w panelu WordPress.

## Podgląd
Plik `preview.html` służy do lokalnego podglądu układu bez uruchamiania WordPress.

## Pobieranie plików
Jeśli pracujesz w tym środowisku, znajdziesz wszystkie pliki w katalogu
`/workspace/mineral-zone`. Możesz spakować projekt do ZIP i pobrać go z panelu
plików w interfejsie Codex lub skopiować bezpośrednio z systemu plików.
